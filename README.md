# AAS India Foundation website

A free, responsive static website for AAS India Foundation (Regd.). It has no paid software, tracking code, or build step.

## Included on the site

- Foundation logo and activity photographs
- Local Punjab Kesari press coverage
- Phone, email and Ballabgarh / Faridabad address
- Bank-transfer donation details supplied by AAS India Foundation
- Scan-to-donate Axis Bank UPI QR code supplied by AAS India Foundation
- 12A, 80G and CSR partnership information supplied by AAS India Foundation
- Direct email and phone links for volunteers and partners

## Before publishing

- Confirm that the public bank details, QR code, address and contact details are correct.
- Keep the 12A, 80G and CSR registration evidence ready to share when a donor or corporate partner requests it.
- The website's email buttons open the visitor's email app. To collect form submissions later, add a form service or web developer.

## Publish on aasindiafoundation.com

1. Make sure you own `aasindiafoundation.com`; the domain itself is normally a yearly paid service.
2. Upload this entire folder to a free static host such as Cloudflare Pages or GitHub Pages, with `index.html` in the publishing root.
3. In the host's custom-domain settings, add `aasindiafoundation.com` and `www.aasindiafoundation.com`.
4. At the domain registrar, copy the DNS records supplied by the host and enable its free HTTPS certificate.

`CNAME` is already included for GitHub Pages. It can be removed if you use another host.
